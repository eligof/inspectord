Hunt

Ad-hoc and saved queries over stored event history. The grammar is the rule engine's, so a query that finds something becomes a detection rule by copy-paste — for example process.name == "curl" AND event.severity != "info".

This panel is read-only. It runs queries; it never writes them. Saving and deleting a query are inspectorctl hunt save <name> "<query>" and inspectorctl hunt delete <name> — those are the two hunt operations that write durable state, and the CLI is where an authorization prompt can be answered.

since takes 24h / 7d or an ISO-8601 timestamp and defaults to the last 7 days; limit defaults to 500 and is capped at 5000.
